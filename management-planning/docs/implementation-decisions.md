# 実装上の判断

- 承認済みの作成計画を根拠とし、既存の開発・ビルド用プロファイルから独立したパッケージとしました。
- 既存の合成QA XLSXはExcel COMのOpenでエラー0x800A03ECとなりました。原本を修復・変更せず、入力資料の指定範囲はOpen XMLを読み取って抽出します。本文・表のDOCXも同様です。管理ブックの編集・数式計算にはExcel COMを使います。
- XLSX資料の数式は保存済み結果を読み、計算結果が保存されていないセルやエラー値は停止します。原本の再計算はしません。画像、OCR、書式からの意味推定は行いません。
- 初版は末端作業1人担当、明示の日別時間、翌日以降の依存関係です。自動最適化は実装しません。
- テンプレート作成時のartifact-toolレンダーはこのWindowsランタイムで画像を保存した後、プロセス終了時にネイティブエラー0xC0000409が発生しました。通常のビルダーはレンダーを省略して構造・値を検査し、同梱テンプレートの14シートの画像は作成時に別途確認しています。利用時にこのランタイムは不要です。
- Excelが保存した記入済みブックのartifact-tool再取り込みでは、空文字の共有文字列番号の誤表示、IDの数値表示、Excelでは正常な数式のNAMEエラーが生じました。ブックは変更せず、デスクトップExcelの再計算・全入力値比較と、Excelから出力したPDFの表示で検証しました。Excelを実行時の計算エンジンとし、汎用プレビューでの計算互換性は保証しません。
- 取り込みは新ブック・差分を一時領域に作成してから公開します。状態ファイルの更新が失敗した場合は、新版と差分を一時領域へ戻し、現行版を維持します。プロセスやOSの強制終了に対する複数ファイルの完全な原子性までは保証しません。
