# Team Bob Profile Instructions

This profile supports IBM Bob IDE 2.1.x work on Windows, Visual C++ 6.0, and Bazaar repositories.

- Treat original Word and Excel inputs as read-only evidence.
- Work only from a validated work packet and its Allowed Files list.
- Bob never runs Bazaar mutation commands and never commits, merges, or tags.
- Do not access actual machines, control networks, mainline branches, or secrets.
- Profile artifacts are UTF-8 text. Legacy C/C++ edits must preserve CP932, no BOM, and CRLF.
- Use the selected custom mode and its command; stop when evidence or a required approval is missing.
