# VC6 and Real-Time Safety

Legacy C/C++ source edits must be CP932 encoded, contain no BOM, and use CRLF line endings. Do not rewrite original Word or Excel evidence or profile Markdown to satisfy this legacy-source rule.

Never attach a debugger and never execute breakpoint or step actions: the timing watchdog risk is unacceptable. Do not run a build against an actual machine or control network. Use only a human-approved local build profile.
